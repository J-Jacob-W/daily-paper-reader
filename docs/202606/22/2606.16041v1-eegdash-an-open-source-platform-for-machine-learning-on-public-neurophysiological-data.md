## 摘要
公开的神经生理学数据集日益易于获取，但仍难以复用：将一个数据集转化为训练好的模型仍需要数千行代码用于下载、加载、格式修复、窗口化及评估，而符合元数据标准的数据集仍可能加载失败。EEG-Dash是一个软件资源，它编录了来自OpenNeuro和NEMAR档案库的791个公开存档记录（39,778名参与者，超过86,051小时），涵盖脑电图（EEG）、脑磁图（MEG）、颅内脑电图（iEEG）、肌电图（EMG）和功能性近红外光谱（fNIRS）。它将每个数据集暴露为一个可导入、可查询的类，保留信号属性并无需自定义代码即可加载到机器学习工作流中，将信号处理委托给MNE-Python，窗口化委托给Braindecode，格式合规性委托给官方脑成像数据结构（BIDS）验证器。一个元数据优先的注册表增加了语义搜索、格式修复层、从每个源出版物自动提取的数据集级标签，以及一个特征提取框架。该目录包含每条记录的加载性和合规性元数据，支持基准测试、模型开发和跨数据集分析。

## Abstract
Public neurophysiological datasets are increasingly accessible but remain hard to reuse: turning one into a trained model still takes thousands of lines of code for download, loading, format repair, windowing, and evaluation, and a dataset that meets metadata standards can still fail to load. EEG-Dash is a software resource that catalogues 791 publicly archived recordings (39,778 participants, over 86,051 hours) spanning electroencephalography (EEG), magnetoencephalography (MEG), intracranial EEG (iEEG), electromyography (EMG), and functional near-infrared spectroscopy (fNIRS) from the OpenNeuro and NEMAR archives. It exposes each dataset as an importable, queryable class that preserves signal attributes and loads into machine-learning workflows without custom code, delegating signal handling to MNE-Python, windowing to Braindecode, and format compliance to the official Brain Imaging Data Structure (BIDS) validator. A metadata-first registry adds semantic search, a format-repair layer, automatic dataset-level tags drawn from each source publication, and a feature-extraction framework. The catalogue, with per-record loadability and compliance metadata, supports benchmarking, model development, and cross-dataset analysis.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：公开的神经生理学数据集（EEG、MEG、iEEG、EMG、fNIRS）虽然日益可获取（符合FAIR原则的可发现与可访问），但**互操作性和可重用性严重不足**。将一个原始数据集转化为可训练的机器学习模型仍需数千行自定义代码，涵盖下载、格式解析、修复、窗口化和评估。即使数据集通过了BIDS官方验证器，仍可能无法被社区加载器读取，导致“合规性-加载性”之间存在实质性脱节。
- **整体含义**：EEG-Dash旨在弥合这一差距，通过构建一个**元数据优先、ML就绪的注册表**，将BIDS格式的公开数据集封装为可直接导入、查询和训练的类，无需用户编写任何数据加载代码，从而**降低神经科学机器学习研究的入门门槛**，支持大规模跨数据集分析与基础模型构建。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心设计原则**：**元数据优先的惰性访问（metadata-first lazy access）**——用户只下载模型实际消耗的信号，而非整个存档的TB级数据。
- **关键技术细节**：
  - **委托 vs. 自有**：信号处理委托给MNE-Python，窗口化委托给Braindecode，BIDS格式合规性委托给官方BIDS验证器，HPC调度委托给Neuroscience Gateway（NSG）。EEG-Dash只拥有**注册表层**、**格式修复层**和**特征提取框架**，避免重新实现已有工具。
  - **元数据注册表**：两层MongoDB文档模型——Dataset文档（研究级元数据：人口、模态、认知领域等）和Record文档（文件级元数据：通道数、采样频率、BIDS实体等）。查询可在不下载原始信号前实现语义搜索和精细过滤。
  - **格式修复管道**：针对文件指针缺陷、元数据缺陷、结构缺陷、格式特定读取失败等四类错误，采用“检测-修复”流程，最小化修改保留原始信号。
  - **ML访问层**：每个BIDS记录转换为Braindecode格式（继承PyTorch Dataset），支持内存映射、窗口化和标签提取，一行代码即可获取DataLoader。
  - **特征提取模块（eegdash.features）**：提供46个预建特征（34个单变量、11个双变量、1个多变量可训练）、10个预处理器，通过共享计算树优化特征计算效率。

## 6. 论文的主要结论与发现

- **合规性-加载性差距**：BIDS验证器状态与ML加载性基本不相关（Spearman ρ = -0.05, 95% CI [-0.14,0.04], p≈0.26）。验证器清洁的数据集仍有12个完全不可加载（37个部分失败），而大量违反BIDS规范的数据集（219个）却能正常加载。因此，**不能将BIDS合规性作为ML就绪的可靠门控**。
- **加载性现状**：标准BIDS加载器能恢复OpenNeuro EEG记录的95.0%（108,322个），EEG-Dash的修复层进一步提升至95.8%（109,291个），但仍有4,740个记录（35个完全不可加载、58个部分加载）不可用。
- **BIDS合规性远低于预期**：仅33.2%（182/548）的OpenNeuro EEG数据集通过官方验证器，主要故障包括TSV值类型错误、文件未列入BIDS、缺失电极坐标系等。
- **平台成效**：EEG-Dash使得从公开数据集到训练循环仅需3行代码（安装→选择数据集→DataLoader），无需任何自定义数据加载代码，从而将ML就绪性变为公开档案的一级属性。

## 7. 优点（方法或实验设计亮点）

- **设计原则清晰**：“元数据优先、惰性访问”和“委托而非重写”使得平台轻量、可持续，且通过向上游贡献修复来提升整个生态系统。
- **大规模实证贡献**：首次量化了BIDS合规性与加载性之间的脱节，揭示了现有FAIR标准的不足（仅关注元数据标准，未保证信号级可加载性）。
- **可重复性**：审计源代码、每记录结局CSV、工具版本均已开源，便于复现。
- **实用导向**：提供可直接运行的教程（端到端笔记本），降低了新用户的上手成本；集成了特征提取模块，支持经典机器学习与深度学习一站式工作流。
- **拓宽覆盖**：涵盖5种模态（EEG、iEEG、MEG、fNIRS、EMG），支持跨数据集分析，为基础模型预训练提供了统一接口。

## 8. 不足与局限

- **事件注释覆盖率低**：v0.8.2中HED标签覆盖不完全，跨研究范式查询受限。
- **信号质量不均**：平台仅修复格式缺陷，不处理采集伪影（电极噪声、线干扰），需要用户自行清洗。
- **模态不平衡**：EEG占绝对主导（659/791数据集），iEEG、MEG、fNIRS、EMG数量远少，且健康参与者远超临床群体，跨模态/临床结论推广需谨慎。
- **感知属性未测量**：界面一致性、完整性、简洁性通过构造保证，但可读性和可理解性需要用户评分，尚未进行。
- **工具版本依赖**：合规性与加载性均为动态属性（随BIDS验证器和mne-bids版本变动），审计结果仅代表固定版本下的快照，需持续监测。
- **适用范围声明**：EEG-Dash旨在用于方法研究和ML基准测试，不适用于临床诊断或医疗决策。
- **未提供模型训练资源消耗**：未报告平台运行或下游模型训练所需的GPU算力，不利于资源规划。
