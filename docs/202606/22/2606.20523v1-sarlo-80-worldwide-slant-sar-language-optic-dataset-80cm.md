## 摘要
多模态基础模型因大规模光学基准而迅速发展，但合成孔径雷达（SAR）的类似资源仍然有限。现有的SAR-光学数据集主要依赖低分辨率、仅强度的地距检测（GRD）产品，未保留复值SAR测量或原生采集几何，这限制了基于物理的多模态学习。特别是，结合甚高分辨率（VHR）SAR SLC、对齐的光学图像和自然语言描述的大规模公共数据集仍然缺乏。我们提出了一个VHR SAR-光学-文本数据集，该数据集基于作为传感器无关复数数据（SICD）分发的开源Umbra聚束模式采集。从约2500个全球场景（VV/HH，20厘米-2米原生分辨率）中，我们通过带限FFT重采样将所有SAR数据标准化为80厘米斜距网格，并将图像切分为1024x1024的图块。对于每个SAR图块，我们检索高分辨率光学图块，并使用局部坐标对应将其扭曲到SAR网格中，以实现局部像素级对齐。我们进一步为每个样本生成三种描述变体（短/中/长），以支持视觉-语言训练和评估。我们的数据集包含119,566个三元组（复数幅度斜距SAR图块、对齐的光学图块、自然语言描述），覆盖72个国家的257个地点以及广泛的地物类型和基础设施。我们发布了固定的训练/验证/测试划分以及完整的预处理和基线代码，以实现在原生SAR几何下的跨模态检索和条件生成的多模态对齐的可重复基准测试。该数据集在Hugging Face Hub上公开提供，网址为https://huggingface.co/datasets/ONERA/SARLO-80。

## Abstract
Multimodal foundation models have advanced rapidly thanks to large optical benchmarks, but comparable resources for synthetic aperture radar (SAR) remain limited. Existing SAR--optical datasets largely rely on low-resolution, intensity-only Ground Range Detected~(GRD) products and do not preserve complex-valued SAR measurements or native acquisition geometry, which restricts physically grounded multimodal learning. In particular, large-scale public datasets combining very-high-resolution (VHR) SAR SLC, aligned optical imagery, and natural-language descriptions are still lacking. We present a VHR SAR--optical--text dataset built from open-access Umbra spotlight acquisitions distributed as Sensor Independent Complex Data (SICD). From around 2,500 worldwide scenes (VV/HH, 20cm--2m native resolution), we standardize all SAR data to an 80cm slant-range grid via band-limited FFT resampling and tile the imagery into 1024 by 1024 patches. For each SAR patch, we retrieve a high-resolution optical tile and warp it into the SAR grid using local coordinate correspondences for local pixel-level alignment. We further generate three caption variants (SHORT/MID/LONG) per sample to support vision--language training and evaluation. Our dataset contains 119,566 triplets (complex and amplitude slant-range SAR patch, aligned optical patch, natural-language description) covering 257 locations across 72 countries and a broad range of land types and infrastructures. We release fixed train/validation/test splits and the full preprocessing and baseline code to enable reproducible benchmarks for multimodal alignment on cross-modal retrieval and conditional generation in native SAR geometry. The dataset is publicly available on the Hugging Face Hub at https://huggingface.co/datasets/ONERA/SARLO-80.

## 2. 论文提出的方法论

### 核心思想
- 从Umbra卫星的开源聚束模式SICD产品出发，通过带限频域重采样将所有SAR数据标准化到统一80 cm斜距网格，切分为1024×1024图块。然后利用局部坐标对应将高分辨率光学影像扭曲对齐到SAR几何，并为每个样本生成三种长度（短/中/长）的自然语言描述。最终形成119,566个三元组（复数幅度SAR图块、对齐光学图块、文本描述）。

### 关键技术细节与流程
1. **源数据处理**：选择约2,500个全球场景（VV/HH极化，入射角10°–70°，原生分辨率20 cm–2 m）。
2. **频域重采样至80 cm**：对每景SICD场景，在2D频域进行带限重采样——若原生间隔小于80 cm则裁剪频谱中央（降采样），若大于80 cm则零填充频谱（升采样），再逆傅里叶变换得到标准化复数图像。该操作遵循Shannon-Nyquist准则，不引入几何畸变。
3. **地理定位网格**：利用SICD元数据，对标准化后的复数图像建立密集像素网格，通过`image_to_ground`投影获得每个像素的ECEF坐标，再转换为WGS84经纬度/高度（LLH）。每个场景保存两个对齐网格（ECEF和LLH），用于后续切块。
4. **图块切分**：将标准化场景以512像素步长切分为1024×1024的重叠图块，每块存储复数SAR数组、幅度PNG预览、对应的LLH/ECEF坐标块。
5. **光学配对与对齐**：根据SAR图块的地理范围检索高分辨率光学瓦片（从Google Satellite TMS下载，zoom=19），利用SAR图块四角与光学像素坐标的对应关系，估计一个仿射变换矩阵 \(A_{sar→opt}\)（2D仿射，最小二乘拟合）。然后对每个SAR像素 \((x,y)\) 计算光学坐标 \((u,v)\)，通过双线性插值采样光学强度，得到投影到SAR网格上的光学图像 \(I_{opt→sar}(x,y) = I_{opt}(u(x,y), v(x,y))\)。超出光学瓦片的像素置零。
6. **描述生成**：使用CogVLM2模型对投影后的光学图像生成三种描述（短/中/长），并通过LLM后处理去除颜色词和推测性表述，提高一致性。最终平均长度分别为14.9/25.3/37.1词，词汇量递增。
7. **数据存储与发布**：以WebDataset格式（sharded .tar归档）发布在Hugging Face Hub，总大小约1.42 TB。包含训练/验证/测试划分（按卫星过境轨道分离）。每个样本包含：SAR幅度图像（.sar.jpg）、复数SAR数组（.sar.npy）、SICD元数据（.sicd.xml）、几何与描述元数据（.meta.json）。光学图像不直接分发，仅提供重建元数据和参考代码（因第三方许可限制）。

### 公式
- 仿射变换：\(\tilde{p}_{opt} = A_{sar→opt} \tilde{p}_{sar}\)，其中 \(\tilde{p}_{sar} = [x, y, 1]^T\)，\(\tilde{p}_{opt} = [u, v, 1]^T\)，\(A_{sar→opt}\) 是3×3矩阵。
- 逆扭曲：\(I_{opt→sar}(x,y) = I_{opt}(u(x,y), v(x,y))\)，非整数坐标用双线性插值。
