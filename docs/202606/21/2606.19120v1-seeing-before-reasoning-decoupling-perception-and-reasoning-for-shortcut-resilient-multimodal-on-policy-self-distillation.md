## 摘要
在线自蒸馏（OPSD）利用模型自身的生成数据训练模型，并使用冻结副本提供基于参考目标的条件化密集词元级目标。这种方法在大型语言模型（LLM）推理中效果良好，但直接扩展到多模态大语言模型（MLLMs）可能产生捷径：特权目标可能主要根据文本参考目标而非图像引导词元。我们提出ViGOS，一种面向MLLM后训练的视觉引导在线自蒸馏框架。学生模型首先撰写视觉描述，然后推理得出最终答案。对于有效生成，仅基于图像的感知教师监督描述部分，而特权推理教师在同一学生前缀上监督推理与最终答案。参考教师仅用于无效生成以恢复输出格式。在通用视觉-语言、专家推理、视觉数学、空间定位和视觉语言先验基准测试中，ViGOS保留了OPSD的主要优势，并在易产生捷径的场景中改善了图像引导行为。

## Abstract
On-policy self-distillation (OPSD) trains a model on its own rollouts and uses a frozen copy to provide dense token-level targets conditioned on a reference target. This works well for LLM reasoning, but a direct extension to multimodal large language models (MLLMs) can create a shortcut: the privileged target may guide tokens mainly based on the text reference target rather than the image. We propose ViGOS, a visually grounded OPSD framework for MLLM post-training. The student first writes a visual description and then reasons toward the final answer. For valid rollouts, an image-only perception teacher supervises the description, while a privileged reasoning teacher supervises the reasoning and final answer on the same student prefix. A reference teacher is used only for invalid rollouts to recover the output format. Across general vision-language, expert reasoning, visual math, spatial grounding, and visual-language-prior benchmarks, ViGOS keeps the main benefits of OPSD and improves image-grounded behavior in shortcut-prone settings.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：将在线自蒸馏（OPSD）从纯文本推理直接扩展到多模态大语言模型（MLLMs）时，会出现一种**捷径风险**：特权教师能够访问参考答案，且文本信号通常比图像更容易利用，导致教师可能在学生尚未充分描述图像内容之前，就基于参考答案引导学生的推理和最终输出。结果学生学会了与答案一致的推理路径，但视觉基础薄弱，即依赖文本/语言先验而非图像证据。
- **背景**：OPSD在LLM推理中效果显著（如Self-Distilled Reasoner），但多模态场景下视觉信息易被忽视，类似VQA中的语言先验和捷径学习问题（Geirhos et al., 2020; Deng et al., 2025）。现有RLVR方法仅提供稀疏结果级奖励，而OPSD提供密集词元级监督，但直接使用会导致上述捷径。
- **意义**：需要一种适应多模态特性的OPSD变体，在保留密集监督优势的同时，防止答案过早驱动推理，从而提升模型对真实图像的依赖和鲁棒性。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：解耦感知（Perception）与推理（Reasoning），让学生**先描述图像再推理**，并用不同的教师角色监督不同阶段。
  - 学生生成结构化输出：`y = (d, r, a)`，其中`d`为视觉描述，`r`为推理过程，`a`为最终答案（格式：`<description> d </description> <think> r </think> \boxed{a}`）。
  - 训练时，解析器提取描述词元集`T_d`、推理词元集`T_r`、答案词元集`T_a`，并标记无效生成（格式错误等）。
- **关键技术**：三种冻结的教师角色（基于同一初始模型的冻结副本）：
  1. **图像仅感知教师（q_img）**：仅以图像为外部上下文（不提供问题文本或参考答案），监督描述词元`T_d`，确保描述基于视觉证据。
  2. **特权推理教师（q_rea）**：使用图像、问题、参考答案作为上下文，监督推理和答案词元`T_r ∪ T_a`，提供答案引导但仅作用于描述之后的部分。
  3. **参考教师（q_ref）**：仅在无效生成时使用（格式错误），对整个输出执行反向KL散度，恢复输出格式。
- **损失函数**：
  - 感知损失：`L_perc = E[(1 - m_inv) Σ_{t∈T_d} KL(q_img,t || p_θ,t)]`
  - 推理损失：`L_rea = E[(1 - m_inv) Σ_{t∈T_r∪T_a} KL(q_rea,t || p_θ,t)]`
  - 参考回退损失：`L_ref = E[m_inv Σ_{t∈T_y} KL(p_θ,t || q_ref,t)]`（反向KL）
  - 总损失：`L_ViGOS = λ_perc L_perc + λ_rea L_rea + λ_ref L_ref`
- **流程**（图3）：
  1. 学生基于图像和问题采样结构化轨迹`y`。
  2. 解析器提取词元掩码并检测无效性。
  3. 有效轨迹：感知教师监督`T_d`，推理教师监督`T_r∪T_a`；无效轨迹：参考教师监督全部词元。
  4. 推理时仅使用学生模型，删除所有教师。

## 6. 主要结论与发现

- ViGOS保留了OPSD在多模态推理基准上的主要增益（平均Pass@5和Avg@5均提升），**没有牺牲标准性能**。
- 在先验敏感基准（ViLP）上，ViGOS**显著提升了Score**（图像驱动正确率），同时保持了高Prior（先验对齐正确率），表明模型更倾向于使用真实图像内容而非语言先验。
- PALR诊断显示，ViGOS将推理-答案段的特权答案泄露率从OPSD的17.26%（3B）/26.01%（7B）降低到6.33%/7.56%，确认了解耦设计的有效性。
- 消融实验表明，感知损失、推理损失、参考回退三者均不可或缺，其中移除参考回退会导致ViLP Score大幅下降（从69.84降至63.25）。
- 同prompt实验表明，结构化提示本身有帮助，但ViGOS的监督分离带来了额外收益。
- 结论：**解耦感知与推理的OPSD框架有效抑制了多模态模型的捷径学习，提升了视觉依赖的可靠性和鲁棒性**。

## 7. 优点：方法或实验设计上的亮点

  - 明确识别并形式化了多模态OPSD中的捷径问题（PALR诊断）。

## 8. 不足与局限

- **实验覆盖**：
  - 仅在Qwen2.5-VL（3B和7B）上验证，未在其他MLLM架构（如LLaVA、InternVL）上测试，泛化性未知。
  - 训练仅使用一个数据集（Vision-SR1-47K），未对比不同训练数据规模或分布下的效果。
  - 超参数（如λ_reference=2.0）未做系统调整（仅一个默认值）。
- **潜在局限**：
  - 生成的描述可能不完整或不正确，导致推理教师基于错误描述依然可能产生误差。
  - 图像仅感知教师可能生成通用描述（未用问题文本），降低描述与任务的相关性。
  - 训练需要额外的教师前向传播（三个教师角色），计算开销比vanilla OPSD更大（附录E.2显示使用8×A100，但未对比时间）。
  - PALR诊断本身有局限性（仅用单一错误答案反事实和单一错误图像反事实），不能完全归因所有捷径。
  - 在部分基准（如MM-Vet、MMMU-Pro）上Avg@5有时低于Baseline或OPSD，表明回答稳定性仍可在更难的符号推理任务上改进。
- **应用限制**：需要模型能稳定生成结构化输出（描述+推理+答案），对不擅长格式化生成的小模型可能无效；回退机制增加了实现复杂度。
