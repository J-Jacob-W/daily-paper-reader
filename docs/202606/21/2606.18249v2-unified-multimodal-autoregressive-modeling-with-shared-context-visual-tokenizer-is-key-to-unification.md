## 摘要
统一多模态建模旨在将视觉理解与生成集成到单一系统中。然而，现有方法通常依赖两个不同的视觉分词器，这分割了表示空间并阻碍了真正的统一建模。我们提出UniAR，一个统一的自回归框架，其中单个离散视觉分词器作为理解与生成之间的关键桥梁，使得模型能够直接解释自身生成的视觉令牌，无需额外的重新编码。UniAR采用预训练的视觉编码器，结合多级特征融合和无查找的逐位量化方案，在保留高层语义和底层细节的同时，以最小代价扩展有效视觉词汇表。在此基础上，统一自回归模型采用并行逐位预测，共同预测空间分组的多级视觉编码，显著缩短视觉序列长度并加速生成。最后，基于扩散的视觉解码器对离散视觉令牌进行解码，生成高保真图像。通过大规模预训练，随后进行监督微调和强化学习，UniAR在图像生成和图像编辑上达到了最先进性能，同时在多模态理解基准测试中保持竞争力。项目页面：https://sharelab-sii.github.io/uniar-web。

## Abstract
Unified Multimodal Modeling aims to integrate visual understanding and generation within a single system. However, existing approaches typically rely on two disparate visual tokenizers, which splits the representation space and hinders truly unified modeling. We propose UniAR, a unified autoregressive framework where a single discrete visual tokenizer serves as the key bridge between understanding and generation, enabling a shared context in which the model can directly interpret its own generated visual tokens without additional re-encoding. UniAR adapts a pretrained vision encoder with multi-level feature fusion and a lookup-free bitwise quantization scheme, preserving both high-level semantics and low-level details while scaling the effective visual vocabulary at minimal cost. Building on this, the unified autoregressive model adopts parallel-bitwise-prediction to jointly predict spatially grouped, multi-level visual codes, substantially reducing visual sequence length and accelerating generation. Finally, a diffusion-based visual decoder operates on discrete visual tokens to decode high-fidelity images. Through large-scale pre-training, followed by supervised fine-tuning and reinforcement learning, UniAR achieves state-of-the-art performance on image generation and image editing while remaining competitive on multimodal understanding benchmarks. The project page is available at https://sharelab-sii.github.io/uniar-web.

## 1. 论文的核心问题与整体含义（研究动机和背景）

当前统一多模态建模（Unified Multimodal Modeling）的目标是将视觉理解（understanding）和视觉生成（generation）集成到同一个系统中。然而，现有方法通常依赖**两个不同的视觉分词器（tokenizer）**——一个用于理解（侧重高层语义），一个用于生成（侧重低层细节），导致表示空间分裂，生成的图像必须经过理解分词器的重新编码才能被模型解读，破坏了“共享上下文”的初衷，阻碍了真正意义上的统一。

UniAR 的核心动机是：**使用一个单一的离散视觉分词器作为理解与生成之间的桥梁**，使模型能够在共享上下文中直接解释自身生成的视觉令牌，无需重新编码。论文认为“共享上下文-视觉分词器”是实现真正统一的关键。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
UniAR 是一个统一的自回归（autoregressive）框架，包含三个核心组件：
- **统一视觉分词器（Unified Visual Tokenizer）**：将图像编码为离散语义令牌，同时服务理解、生成和编辑。
- **统一自回归模型（Unified Autoregressive Model）**：使用 next-token prediction 范式联合预测文本和视觉令牌。
- **视觉解码器（Visual Decoder）**：基于扩散 Transformer（DiT），将视觉令牌解码为高保真图像。

### 关键技术细节

#### 视觉分词器设计
- 采用**多级特征融合（Multi-level Feature Fusion）**：从视觉编码器（ViT）的多个中间层提取特征，浅层保留低层细节（纹理、颜色），深层捕捉高层语义，再通过特征合并（Merger）聚合到一个令牌中，同时满足生成和理解的需求。
- 采用**无查找逐位量化（Lookup-free Bitwise Quantization）**：使用 Binary Spherical Quantization (BSQ) 将视觉特征量化为二进制向量（如64位向量），无需显式码本，理论词汇表大小可达 2^64，大幅扩展表示能力且仅增加极小开销。
- 量化过程：`u = BSQ(MLP_in(v))`，然后通过 `v' = MLP_out(u)` 重建，并冻结视觉编码器以保证离散索引的一致性。

#### 统一自回归建模
- 基于预训练的大语言模型（LLM，使用 Qwen3-8B），将视觉理解和生成任务同等对待，均采用 teacher-forcing 训练。
- 引入**并行逐位预测（Parallel Bitwise Prediction）**：在一个 2×2 空间网格内同时预测多级视觉二进制向量，将视觉序列长度压缩 32 倍（一个 1024×1024 图像仅需预测 256 个视觉令牌），显著加速生成。
- 视觉预测头：使用 RMSNorm 和线性投影，输出维度 `d_vis = 2 × d_BSQ × g`，其中 `g = n_level × n_spatial`。
- 训练目标：`L_AR = L_text + λ_vis · L_vis`，文本部分仅对理解数据集计算，视觉部分对理解和生成数据集均计算。
- **随机视觉索引翻转（Random Visual Index Flipping）**：在训练时随机翻转一部分二进制位，模拟自回归采样时的累积误差，提高生成稳定性。

#### 视觉解码器
- 基于预训练的 Diffusion Transformer (DiT)，将视觉令牌作为条件（通过 element-wise addition 注入）。
- 使用条件流匹配（Conditional Flow Matching, CFM）优化。
- 引入**分辨率上采样**：对视觉条件信号进行双三次插值，使得 AR 模型只需预测较低分辨率令牌，解码器再上采样到高分辨率（如 512→1024），进一步降低 AR 预算。
- 解码器仅以视觉令牌为输入，**不依赖文本提示**，所有语义和布局生成都由 AR 模型完成。

## 6. 论文的主要结论与发现

1. **共享视觉分词器是实现统一多模态建模的关键**：通过单一分词器将理解与生成置于同一表示空间，模型可以自动获得交互相应能力（即使未训练多轮交互相应数据，也能回答关于自己生成图像的细粒度问题）。
2. **多级特征融合+无查找位量化** 能够同时满足生成（低层细节）和理解（高层语义）的需求，且词汇表扩展高效。
3. **并行位预测** 显著缩短视觉序列长度，加速生成（512×512 图像仅需 256 令牌，1024×1024 图像借助解码器上采样仅需 256 令牌），推理速度远优于 Janus-Pro 和 X-Omni。
4. **强化学习** 可有效提升生成质量，尤其是文本渲染能力，且可无缝集成到离散令牌自回归框架中。
5. UniAR 在图像生成（GenEval 0.86）、文本渲染（OneIG-EN 0.873, LongText-EN 0.917）和图像编辑（ImgEdit 3.73）上达到 SOTA，在多模态理解上保持竞争力（DocVQA 91.4, InfoVQA 70.0, OCRBench 833）。
