## 摘要
基于Transformer的多模态模型依赖注意力机制来整合跨异构模态的信息。尽管取得了成功，现有的多模态注意力公式要么通过成对点积交互的集合计算得分，要么将所有模态拼接成键值，甚至在需要多个模态联合参与的情况下也是如此。因此，当前的方法要么在模态数量上产生二次复杂度，要么无法显式建模依赖于多种表示联合配置的交互。在这项工作中，我们引入了体素多模态交叉注意力（VMA），这是一种新颖的交叉注意力机制，其中注意力得分被定义为查询和多个模态特定键的联合几何的函数。VMA计算跨多个模态的查询和键向量所张成的体积，捕捉超越成对相似性的联合多模态依赖关系，从而实现对任意顺序模态交互的原生建模。我们将VMA集成到我们新颖的多模态Transformer架构中，命名为GRAMformer，该架构明确设计用于整合任意数量的模态。我们在多模态学习任务上评估了所提出的模型，展示了改进的有效性和效率。

## Abstract
Transformer-based multimodal models rely on attention mechanisms to integrate information across heterogeneous modalities. Despite their success, existing multimodal attention formulations compute their scores through collections of pairwise dot-product interactions or by concatenating all the modalities into the keys, even when multiple modalities should be jointly involved. As a consequence, current approaches either incur quadratic complexity in the number of modalities or fail to explicitly model interactions that depend on the joint configuration of multiple representations. In this work, we introduce the Volumetric Multimodal cross-Attention (VMA), a novel cross-attention mechanism in which attention scores are defined as a function of the joint geometry of a query and multiple modality-specific keys. VMA computes the volume spanned by query and key vectors across multiple modalities, capturing joint multimodal dependencies beyond pairwise similarity, enabling native modeling of any-order modality interactions. We integrate VMA into our novel multimodal transformer architecture, named GRAMformer, explicitly designed to integrate any number of modalities. We evaluate the proposed model on multimodal learning tasks, demonstrating improved effectiveness and efficiency.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：现有Transformer多模态交叉注意力机制存在根本性局限：要么通过成对点积（pairwise dot-product）独立计算每个查询与每个模态键的相似度，导致模态数量增多时复杂度呈二次增长，且无法捕捉三个及以上模态的联合交互；要么将所有模态的键值拼接成一个长序列，但这样依然只计算查询与单个键的相似度，没有显式建模多模态之间的联合关系。
- **研究动机**：多模态信息（如文本、音频、视频）在语义上通常是**对齐且相互依赖**的（例如，视频帧、声音和字幕同时表达同一情感），因此需要一种能**原生建模任意阶模态交互**（any-order modality interactions）的注意力机制，同时保持计算高效。
- **整体含义**：作者提出基于**体素（volume）几何度量**的新型交叉注意力——Volumetric Multimodal cross-Attention (VMA)，将注意力分数定义为查询与多个模态键向量**所张成的平行多面体的体积**的函数，从而在单个注意力操作中联合评估所有模态的相似性。该机制被集成到新架构GRAMformer中，证明在多模态任务上更有效且更轻量。

### 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：用几何体积替代成对点积作为多模态相似度度量。向量集合的**体积越小，表示它们越共线（即语义越一致）**，反之越大则表示信息更独立。通过联合体积计算，注意力可以同时感知所有模态的全局对齐程度。
- **关键技术细节**：
  - **输入设置**：查询向量 `q ∈ ℝ^d`，每个序列位置有M个对齐的键向量 `{k₁, ..., k_M}`（假设模态已对齐）。
  - **体积计算**：构造矩阵 `Z = [q, k₁, ..., k_M] ∈ ℝ^{d×(M+1)}`，计算Gram矩阵 `G = ZᵀZ ∈ ℝ^{(M+1)×(M+1)}`，体积为 `Vol = sqrt(det(G) + ε)`。
  - **注意力分数**：`s(q, k₁, ..., k_M) = -β · Vol + Σₘ ⟨q, k_m⟩/√d`，其中`β`控制高阶项注入量，点积项保留成对交互以稳定训练。
  - **注意力权重**：对所有位置j的`A_{i,j}`做softmax，得到第i个查询对第j个多模态键组的概率分布。
  - **值聚合**：对每个模态m，用注意力权重加权该模态的值矩阵 `V_m`，再通过查询相关的门控机制 `σ(W_{gate,m} Q)` 逐元素相乘，最后取所有模态的均值作为输出。
  - **多头扩展（M-VMA）**：将输入投影到H个子空间（`d_h = d/H`），每个头独立计算VMA，要求 `M+1 ≤ d_h`（实际中通常远小于d_h）。
- **算法流程（文字说明）**：
  1. 对每个查询token，收集所有模态在同一索引位置的键token。
  2. 计算这组向量张成的体积。
  3. 组合体积项和点积项得到logit，softmax后得到注意力权重。
  4. 对每个模态的值分别加权，经门控平均后输出。
  5. 多头情况下并行重复，最后拼接并线性投影。

### 7. 优点
- **创新性强**：首次将几何体积概念引入注意力分数计算，为高阶多模态交互提供原生解决方案，而非通过近似或分解。
- **计算高效**：在M+1 ≪ d的条件下，体积计算复杂度为O(M³)，而传统成对方法在模态数增加时需O(M²)次单独注意力。VMA避免了二次参数/内存增长，如图6所示。
- **通用性与可扩展性**：支持任意数量模态（M+1 ≤ d即可），无需修改架构；多头实现自然。
- **鲁棒性**：对时序偏移和语义缺失表现稳定（Table 7）。
- **轻量**：相比对比方法，GRAMformer在保持最优性能的同时参数量最少（如MOSI上0.66M vs 其他方法数M乃至数百M）。
