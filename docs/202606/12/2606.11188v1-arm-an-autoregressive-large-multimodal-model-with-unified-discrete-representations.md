## 摘要
本文介绍了ARM，一种基于离散表示的自回归模型，它在下一个词元预测框架内统一了图像理解、生成和编辑。ARM基于三项努力：首先，我们训练了一个离散语义视觉分词器，将图像映射为紧凑的词元序列。我们的分词器通过多个目标进行监督，这些目标共同促进语义可区分性、语言对齐和忠实重建，从而在共享潜在空间中支持多样化任务。在此基础上，我们在大规模文本和图像词元序列上训练了一个7B自回归模型，无缝地发展了视觉语言感知和生成能力。最后，为了进一步改进文本到图像生成和指令引导编辑的偏好对齐行为，ARM应用强化学习（RL）来优化任务级目标，如视觉质量、指令遵循和编辑一致性。令人惊讶的是，结果表明RL不仅显著提升了目标任务的性能（例如，将WISE总体得分从0.50提高到0.56，GEdit-Bench-EN G_O从5.75提高到6.68），而且还在文本到图像生成和编辑之间诱导了跨任务协同效应。总的来说，这些发现突显了自回归建模，当与强大的表示和偏好优化相结合时，可以作为多模态智能的可扩展基础。代码：https://github.com/wdrink/ARM。

## Abstract
This paper introduces ARM, a discrete representation-based AutoRegressive Model that unifies image understanding, generation, and editing within a next-token prediction framework. ARM is built on three efforts: first, we train a discrete semantic visual tokenizer that maps images into compact token sequences. Our tokenizer is supervised with multiple objectives that jointly promote semantic discriminability, language alignment and faithful reconstruction, thereby supporting diverse tasks in a shared latent space. With this, we train a 7B autoregressive model over large-scale text and image token sequences, seamlessly developing vision-language perception and generation capabilities. Finally, to further improve preference-aligned behavior for text-to-image generation and instruction-guided editing, ARM applies reinforcement learning (RL) to optimize task-level objectives such as visual quality, instruction adherence, and edit consistency. Surprisingly, the results show that RL not only substantially improves performance on the target tasks (e.g., raising WISE overall from 0.50 to 0.56, GEdit-Bench-EN G_O from 5.75 to 6.68), but also induces cross-task synergy between text-to-image generation and editing. Collectively, these findings highlight autoregressive modeling, when paired with strong representations and preference optimization, as a scalable foundation for multimodal intelligence. ## 1. 论文的核心问题与整体含义（研究动机和背景）

*   **核心问题：** 现有多模态大模型（LMMs）在统一图像理解、生成和编辑等任务时，面临“结构性碎片化”问题。这主要源于理解和生成任务对视觉表示的要求存在长期固有的不匹配：理解任务需要语义丰富的特征，而生成任务则需要包含精细纹理细节的特征。
*   **现有方法的局限：**
    *   **分离式架构**（如`Janus-Pro`, `Bagel`）使用单独的视觉编码器，导致模型结构复杂、计算开销大，需要额外的建模能力来桥接两个不同的视觉潜在空间。
    *   **生成导向的统一方法**（如`Emu3`, `Chameleon`）虽然统一了表示，但为了合成保真度会显著牺牲理解性能。
*   **研究动机：** 探索一种完全统一的、高效的框架，能够在一个单一的、共享的离散表示空间内无缝地处理视觉感知（理解）、合成（生成）和修改（编辑），无需依赖分离的视觉通路。

## 2. 论文提出的方法论：核心思想、关键技术细节

*   **核心思想：** 构建一个三阶段的训练流程，核心是训练一个统一的离散视觉分词器，将图像转换为紧凑且语义丰富的离散词元序列，然后在一个自回归（AR）变压器骨干网络上进行建模和优化。
*   **第一阶段：统一离散视觉分词器（Unified Discrete Visual Tokenizer）**
    *   **架构：** 基于一个冻结的`SigLIP2`视觉编码器，通过投影模块和`Finite Scalar Quantization (FSQ)`进行离散化，最后由一个对称的投影模块和用于解码的扩散模型构成。
    *   **关键技术：** 使用**四个互补的监督目标**联合训练：
        1.  **Caption Loss (L_cap):** 冻结的0.5B语言模型，通过交叉熵损失确保表示与语言模型对齐。
        2.  **Pixel Reconstruction Loss (L_pix):** 一个轻量级的`DiT`解码器在像素空间中进行重建，目标是保留用于高保真合成的低级信息（避免VAE的有损瓶颈）。
        3.  **Sigmoid Loss (L_sig):** 一个对比损失（类似SigLIP），将量化后的视觉嵌入与对应的`SigLIP2`文本嵌入对齐。
        4.  **Feature Distillation Loss (L_feat):** 通过最小化余弦距离，将量化后的嵌入与原始`SigLIP2`视觉特征进行蒸馏匹配。
    *   **公式：** 总损失函数为 `L_Tok = λcap*L_cap + λpix*L_pix + λsig*L_sig + λfeat*L_feat`，其中λ值分别设为1, 5, 5, 1。
    *   **解词器：** 使用一个高容量的潜在扩散模型（`FLUX.1[dev]`）作为主要的解词器，以生成高质量图像，而像素空间解码器仅用于训练监督。

*   **第二阶段：自回归大模型训练（Autoregressive LMM Training）**
    *   **流程：** 在得到离散视觉词元后，将文本和图像词元组合成交错的序列，使用标准的**下一个词元预测（next-token prediction）** 目标训练一个7B的自回归模型。公式为 `L_ARM = -Σ log pθ(yj|y<j)`。
    *   **训练阶段：** 包括四个阶段：
        1.  **预训练（PT）：** 在2.5T多模态词元上训练，处理原生分辨率图像。
        2.  **持续训练（CT）：** 在2.5T词元上训练，提高分辨率并增加交错数据比例以增强推理能力。
        3.  **监督微调（SFT）：** 使用0.2B高质量指令跟随数据词元进行微调，提升理解能力。
        4.  **强化学习（RL）：** 这是第三阶段。

*   **第三阶段：偏好对齐的强化学习（Preference Alignment via RL）**
    *   **目标：** 通过`GRPO (Group Relative Policy Optimization)`优化视觉词元预测，以更好地对齐人类偏好。
    *   **关键技术：** 针对**文本到图像生成**和**指令引导编辑**任务，分别使用`GPT-o3`和`GPT-4.1`作为奖励模型来评估生成/编辑效果。
    *   **公式：** 优化目标是 `L_GRPO = 1/K Σ [min(ρk * Ak, clip(ρk, 1-ε, 1+ε)*Ak) - β * KL(πθ || πref)]`，其中ρk是概率比，Ak是组内归一化的优势函数。
    *   **关键发现：** 令人惊讶的是，RL阶段不仅在目标任务上取得了显著提升，还在**文本生成**和**图像编辑**任务之间诱导了**跨任务协同效应**（cross-task synergy）。

## 6. 论文的主要结论与发现

1.  **统一架构的有效性：** ARM通过统一的离散视觉表示和自回归建模框架，成功地在单一模型中实现了图像理解、生成和编辑，并在各项任务上取得了具有竞争力的性能。
2.  **统一视觉分词器的关键性：** 通过结合语义对齐（`L_cap, L_sig, L_feat`）与重建保真度（`L_pix`）的互补监督，训练出的分词器能够同时保留识别所需的高级语义和生成所需的精细细节，这是统一架构成功的基石。
3.  **RL的跨任务协同效应：** 这是论文最引人注目的发现。针对**文本生成**或**图像编辑**的RL优化，不仅显著提升了目标任务性能，还意外地为另一个任务带来了正面提升。联合训练效果最佳，且理解性能保持稳定。
4.  **离散表示的优势：** 离散化的视觉表示使得可以将生成任务自然地建模为token级别的预测，从而方便地应用类似LLM中的RL方法。同时，语义分词器减少了对无分类器引导（CFG）的依赖。
5.  **解码器角色分离：** LMM主要预测高级语义（布局、物体组成），而扩散解码器主要负责将这些语义Token“渲染”成像素，模型能力主要决定了生成内容，解码器能力决定了视觉质量。
