## 摘要
现实世界的多模态系统必须能够应对低质量数据，例如传感器噪声、不完整的多模态数据和冲突输入。然而，现有的可信融合方法依赖于模型自身的预测置信度来判断数据质量。这造成了循环依赖：当模型自信但错误时，这些方法无法检测到错误。为了打破这一循环，我们提出了基于几何的多模态融合（GMF）。我们不依赖预测，而是通过测量输入在潜在空间中所需要的传输校正量来评估可靠性。我们利用修正流实现扩散薛定谔桥传输，其中初始速度的平方给出了一个高效的学习校正分数。有效数据的平方速度幅度较低，而有噪声、不完整或冲突的数据则需要更强的传输校正。这种基于几何的可靠性信号作为一个独立的评判者，即使在分类器被欺骗时也能有效地标记不可靠输入。大量实验表明，与基于置信度的基线方法相比，GMF显著提高了对严重传感器噪声和语义冲突的鲁棒性。

## Abstract
Real-world multimodal systems must be robust against low-quality data, such as sensor noise, incomplete multimodal data and conflicting inputs. However, existing trustworthy fusion methods rely on the model's own prediction confidence to judge data quality. This creates a circular dependency: when a model is confident but wrong, these methods fail to detect the error. To break this loop, we propose Geometry-based Multimodal Fusion (GMF). Instead of relying on predictions, we evaluate reliability by measuring how much transport correction the input needs in latent space. We implement Diffusion Schrödinger Bridge transport with Rectified Flow, where the squared initial velocity gives an efficient learned correction score. Valid data has low squared velocity magnitude, while noisy, incomplete data or conflicting data requires stronger transport correction. This geometry-based reliability signal acts as an independent judge, effectively flagging unreliable inputs even when the classifier is fooled. Extensive experiments demonstrate that GMF significantly improves robustness against severe sensor noise and semantic conflicts compared to confidence-based baselines.

### 2. 论文提出的方法论

#### 核心思想
- 将低质量数据（噪声、缺失、语义冲突）视为偏离学习到的数据流形（干净潜在空间）的样本；干净样本所需传输校正小，低质量样本所需校正大。
- 利用扩散薛定谔桥（Diffusion Schrödinger Bridge, DSB）结合修正流（Rectified Flow）实现高效一步传输，以**初始速度的平方**作为传输成本的度量，作为几何可靠性信号。

#### 关键技术细节
- **潜在空间传输建模**：对每个模态 \(m\)，训练一个速度场 \(v_\theta^{(m)}(z,t)\) 将潜在特征 \(z^{(m)}\) 传输到参考先验分布 \(P_{\text{prior}}\)。优化目标为流匹配损失：
  \[
  \mathcal{L}_{\text{RF}}(\theta) = \mathbb{E}_{t,z_0,z_1} \left[ \|v_\theta(z_t,t) - (z_1-z_0)\|^2 \right]
  \]
  其中 \(z_t = (1-t)z_0 + tz_1\)。推理时直接用 \(E_{\text{intra}}^{(m)} = \|v_\theta^{(m)}(z^{(m)},0)\|^2\) 作为模态内传输成本。
- **模态间传输**：对每对模态 \(a,b\) 训练方向特定的速度场 \(v_\Phi^{(a\to b)}\)，将源特征 \(z^{(a)}\) 映射到目标模态的潜在空间，定义映射 \(\Phi_{a\to b}(z)=z+v^{(a\to b)}_\Phi(z,0)\)。模态间传输成本为 \(E_{\text{inter}}^{(a\to b)} = \|\Phi_{a\to b}(z^{(a)}) - z^{(b)}\|^2\)，用于检测语义冲突。
- **融合权重生成**：通过竞争-交互机制合成权重：
  1. **竞争**：基于模态内成本产生基础得分 \(\beta_{\text{comp}}^{(m)} \propto \exp(-E_{\text{intra}}^{(m)}/\tau)\)。
  2. **交互门**：模态 \(m\) 从其他可靠模态接受几何支持，互动门 \(\gamma_{\text{int}}^{(m)}\) 聚合交叉模态共识。
  3. 最终权重 \(w^{(m)}\) 为归一化的 \(\beta_{\text{comp}}^{(m)} \cdot \tilde{\gamma}_{\text{int}}^{(m)}\)，用于加权组合证据，得到融合后 Dirichlet 参数 \(\alpha\)。
- **统一训练目标**：包含几何传输损失 \(\mathcal{L}_{\text{geo}}\)（模态内+模态间流匹配）、任务损失 \(\mathcal{L}_{\text{task}}\)（期望交叉熵 + Dirichlet KL 散度）和冲突感知正则化 \(\mathcal{L}_{\text{reg}}\)。采用分离梯度路径：几何损失只更新速度场，任务损失只更新分类器/证据头。

#### 公式/算法流程简述
- 输入：多模态数据和标签；输出：融合预测。
- 训练循环：对每个 mini-batch，提取特征，采样时间 \(t\sim U[0,1]\)，计算模态内/间传输成本；优化几何损失；冻结几何成本（stop-gradient）计算融合权重与任务损失；更新分类器；附加正则化。
- 推理：一步计算 \(E_{\text{intra}}, E_{\text{inter}}\)，代入公式直接得到权重与预测。

### 6. 论文的主要结论与发现
- **结论**：基于几何的可靠性信号（传输成本）可以作为独立于分类器预测的可靠判据，有效打破循环依赖。GMF在严重噪声、不完整数据和语义冲突场景下显著优于所有基于置信度的基线方法。
- **关键发现**：
  - 模态内传输成本与数据质量成反比，当分类器过度自信时仍能准确识别异常。
  - 模态间传输成本在语义冲突时出现显著高值（几何屏障原理），可指数级抑制冲突模态的权重。
  - 在医疗诊断中，传输成本可将错误样本集中在高风险层，实现有效的风险分层。

### 7. 优点
1. **创新性**：首次把几何传输成本用于多模态融合的可靠性评估，从根本上解决循环依赖。
2. **理论保障**：提供了最优融合权重（定理4.4）和几何屏障原理（定理4.5）的数学证明，保证冲突检测的几何下界。
3. **实验全面**：覆盖噪声、冲突、不完整、医疗风险等多样化场景，消融充分，统计验证。
4. **效率实用**：单步推理（速度网络仅含两层MLP），延迟与轻量基线（PDF、DBF）相当，适合实时部署。

### 8. 不足与局限
1. **依赖编码器质量**：几何可靠性假设潜在空间满足流形分离（Assumption 4.1），若编码器导致特征退化（如模式坍塌），传输成本可能失去信息量。此时GMF只能输出均匀分布，不能恢复丢失的语义信息（论文明确指出）。
2. **计算开销**：虽然推理延迟低，但训练时需为每对模态维护独立的速度网络（对 M 个模态需 M 个模态内网络 + M(M-1) 个模态间网络），模态数增加时参数规模呈平方增长（表12显示3模态时约1.3ms，5模态时约3.3ms，仍可接受）。
3. **实验覆盖深度**：未测试在真实世界对抗样本或联合多模态缺失（如同时缺失两个模态）下的性能；仅测试单一噪声类型（高斯）和固定缺失比例。
4. **对冲突的假设**：语义冲突检测依赖于跨模态映射的局部一致性（ξ ≤ ϵ 条件），实际中可能不完全满足，尤其在训练数据有限的场景。
