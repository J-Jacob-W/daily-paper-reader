## 摘要
多模态大语言模型最近在点式重排序中展现出强劲潜力，通过直接建模查询-文档相关性进行下一词元预测。然而，点式重排序面临跨查询-文档对的显著重复计算问题，而Transformer的因果结构仅允许通过预缓存重用前缀片段。为了解决现有查询优先和文档优先格式与VQA风格提示及计算感知重用的不匹配问题，我们提出一种视觉优先的公式，同时提升了缓存重用效率和重排序性能。然而，剩余计算成本仍然可观，主要来自三个来源：（1）模型深度，我们通过早期退出减少活跃参数；（2）跨段注意力，我们将其限制在少数层的小交互带内；（3）视觉词元，我们通过嵌入器引导的剪枝减少词元数量。这些设计共同构成了miniReranker，在单查询高重用设置下，将重排序运行时间降至密集实现的<1%，同时保持>96%的密集模型性能。

## Abstract
Multimodal large language models (MLLMs) have recently shown strong potential as point-wise rerankers by directly modeling query--document relevance through next-token prediction. However, point-wise reranking suffers from substantial repeated computation across query--document pairs, while the causal structure of transformers allows only prefix segments to be reused via pre-caching. To address the misalignment of existing query-first and document-first formats with both VQA-style prompting and computation-aware reuse, we propose a \textit{vision-first} formulation that improves both cache reuse efficiency and reranking performance. However, the remaining cost is still considerable and stems from three main sources: (1) \textit{model depth}, for which we reduce active parameters via early exit; (2) \textit{cross-segment attention}, which we restrict to a narrow interaction band across a few layers; and (3) \textit{visual tokens}, where we reduce the number of tokens via embedder-guided pruning. Together, these designs form miniReranker, which reduces reranking runtime to <1% of the dense implementation under high-reuse settings for a single query, while preserving >96% of the dense model performance.

- **研究动机**：多模态大语言模型（MLLM）作为点式重排序器时，虽然能通过细粒度 token 级交互提升相关性建模，但因果 Transformer 结构只允许缓存前缀段，导致跨查询-文档对出现大量重复计算。现有查询优先或文档优先的输入格式与 MLLM 预训练的 VQA 风格提示不匹配，且无法最大化昂贵视觉计算的复用，在文本-视觉、视觉-文本等不同场景下均存在效率与性能损失。
- **整体含义**：本文旨在设计一种高效的多模态重排序框架，在保持高质量重排序的前提下，通过输入格式优化和模型级压缩显著降低计算开销，使 MLLM 重排序在实际检索系统中可以大规模部署。

### 2. 方法论
- **核心思想**：提出**视觉优先（Vision-First）**输入格式（始终将视觉内容置于文本之前），以对齐预训练格式并最大化视觉表示的可重用性；在此基础上，通过模型深度、跨段注意力和 token 序列长度三个维度的冗余分析，设计了三种互补的压缩策略：
  - **早期退出（Early Exit）**：发现重排序信号在中间层（约 60% 深度）即饱和，因此直接在该层截断前向传播，减少活跃参数。
  - **交互带（Interaction Band）**：通过层探针实验发现有效跨段信息交互仅集中在少数中间层（如 2B 模型的 8-16 层），因此只在交互带内启用查询-文档注意力，其余层禁用，降低二次交互代价。
  - **嵌入器引导的 token 剪枝（Embedder-Guided Token Pruning）**：利用第一阶段检索器（如 Qwen3-VL-Embedding）已有的注意力权重（各层聚合），选出前 α% 的重要视觉 token，丢弃其余 token，无需额外前向计算。默认保留 50% 视觉 token。
- **技术细节**：三者结合构成 miniReranker，以 Qwen3-VL-Instruct 为骨干，通过 LoRA 进行点式 yes/no 监督微调。推理时视觉输入可预缓存，动态选择查询优先或文档优先以保持视觉优先原则。

### 6. 主要结论与发现
- **视觉优先**格式在微调后仍然优于查询优先和文档优先，且能最大化缓存复用。
- **miniReranker** 在 2B 模型上保持 dense 模型 **96.3%** 的性能，在 4B/8B 上保持 **>98%** 性能。
- 活跃参数降至 **58%**（2B: 1.14B，4B/8B: 2.2B/4.6B）。
- 训练加速约 **3 倍**；在线重排序延迟大幅降低，尤其在视频任务中，单查询 Top-100 重排序运行时降至 **<1%**（密集基线），图像任务降至 **<15%**。

### 7. 优点
- **问题诊断精准**：通过层探针、注意力屏蔽等分析精确定位了深度、跨段交互和视觉 token 三个维度的冗余，针对性设计压缩，而非盲目剪枝。
- **零成本剪枝**：视觉 token 重要性分数复用第一阶段检索器的注意力，不引入额外计算，与现有流水线自然集成。
- **通用性与可扩展性**：方法不限于特定模型，可迁移至其他 MLLM；视觉优先格式适应 T→V、V→T、V→V 多种检索范式。
- **效率分析全面**：不仅报告加速比，还分解各组件贡献，并展示了端到端延迟（含预缓存）。

### 8. 不足与局限
- **仅适用于点式重排序**：不捕获候选间交互，无法直接用于列表式重排序或智能检索。
- **基准覆盖有限**：仅在 MMEB-v2 上实验，缺乏在其他主流重排序基准（如 MS MARCO 多模态变体）上的验证。
- **训练数据自建**：可能导致领域偏差，且未公开数据集，影响可复现性。
- **剪枝依赖上游检索器质量**：如果第一阶段检索器注意力不可靠，剪枝可能丢弃重要 token。
- **视频帧采样未深入讨论**：效率分析虽包含视频，但帧采样策略对计算和性能的影响未独立研究。
- **未报告消融中 token 剪枝比例的影响**：仅固定 50% 剪枝，未探讨不同比例下的权衡。
