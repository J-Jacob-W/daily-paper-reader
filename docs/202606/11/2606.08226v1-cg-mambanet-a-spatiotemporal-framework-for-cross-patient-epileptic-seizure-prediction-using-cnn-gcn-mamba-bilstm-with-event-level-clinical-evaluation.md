## 摘要
从头皮脑电图中预测癫痫发作对于闭环神经刺激治疗至关重要。现有深度学习方法存在两个架构局限性：它们独立建模脑电通道，忽略了通道间的空间同步性，并且直接处理原始时域样本而不进行频率分解。一个方法论上的局限性也影响了该领域：大多数研究采用的数据划分方式允许患者级信息泄露，从而产生乐观的估计，无法泛化到未见过的患者。我们提出了CG-MambaNet，一个解决上述三个局限性的时空癫痫发作预测框架。一个深度可分离CNN前端将每个脑电片段分解为多尺度频谱-时间特征，在序列建模之前捕获从δ到γ波段的动态。一个具有可学习邻接矩阵的双层图卷积网络捕捉通道间的功能同步性，无需特定导联坐标，适用于双极导联（CHB-MIT）和参考导联（SIENA）。一个双向Mamba编码器后接双向LSTM建模长程和短程时间动态，一个双层MLP输出最终的癫痫发作概率。这种串联层次结构确保频率分解先于空间混合，而空间混合先于时间整合。在严格的留一患者交叉验证下（五个独立随机种子），CG-MambaNet在CHB-MIT（n=22）上达到0.8152±0.0176的AUC-ROC，在SIENA（n=6）上达到0.7104±0.0261，超越了所有已发表的无需域适应的跨患者方法。一个通过持续性滤波器合并连续警报窗口的事件级评估框架将CHB-MIT上的错误预测减少到0.32次警报/小时，展示了具有临床意义的警报负担。

## Abstract
Epileptic seizure prediction from scalp EEG is critical for closed-loop neurostimulation therapy. Existing deep-learning methods share two architectural limitations: they model EEG channels independently, neglecting inter-channel spatial synchrony, and process raw time-domain samples without frequency decomposition. A methodological limitation also affects the field: most studies use data splits that permit patient-level information leakage, yielding optimistic estimates that do not generalise to unseen patients. We present CG-MambaNet, a spatiotemporal seizure prediction framework addressing all three limitations. A depthwise separable CNN front-end decomposes each EEG patch into multi-scale spectro-temporal features, capturing delta-to-gamma band dynamics before sequence modelling. A two-layer graph convolutional network with a learnable adjacency matrix captures inter-channel functional synchrony without montage-specific coordinates, applicable to bipolar (CHB-MIT) and referential (SIENA) montages. A bidirectional Mamba encoder followed by a bidirectional LSTM models long- and short-range temporal dynamics, and a two-layer MLP produces the final seizure probability. This serial hierarchy ensures frequency decomposition precedes spatial mixing, which precedes temporal integration. Under strict leave-one-patient-out cross-validation with five independent random seeds, CG-MambaNet achieves AUC-ROC of 0.8152+/-0.0176 on CHB-MIT (n=22) and 0.7104+/-0.0261 on SIENA (n=6), surpassing all published cross-patient methods without domain adaptation. An event-level evaluation framework merging consecutive alarmed windows via a persistence filter reduces false predictions to 0.32 alarms/hour on CHB-MIT, demonstrating clinically meaningful alarm burden.

- **现存三大缺陷**：
  1. **架构缺陷①**：现有深度学习方法独立处理每个EEG通道，忽略通道间的空间同步性（pre-ictal状态的关键神经生理标志）。
  2. **架构缺陷②**：直接处理原始时域样本，未先分解为不同频带成分（δ/θ/α/β/γ），导致样本效率低且跨患者泛化差。
  3. **方法论缺陷**：超过96%的已发表论文使用随机或患者特定数据划分，允许患者级信息泄漏（training和test set包含同一患者窗口），产生乐观估计（如AUC>0.90），无法泛化到未见患者。严格跨患者评估下性能骤降（如Jemal et al.报道CHB-MIT AUC仅0.69，SIENA 0.48）。
- **论文目标**：提出CG-MambaNet，同时解决上述三个缺陷，在严格留一患者交叉验证下实现跨患者癫痫预测，无需域适应即可超越现有方法，并引入事件级假阳性率评估框架以匹配临床设备触发逻辑。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- 设计一个**四阶段串联架构**（CNN → GCN → Mamba → BiLSTM），遵循严格信号处理层次：**频率分解先于空间混合，空间混合先于时间整合**。
- 串联顺序是原则性的：若并行门控，则Mamba需在原始样本上建模时间动态（无频率分解），且GCN无法在结构清晰的通道-时间表示上操作。

### 2.2 关键技术细节

1. **CNN频谱-时间前端（深度可分离卷积）**：
   - 输入：每个10秒窗口被分为10个1秒片段（patch），每个patch包含200个样本（200 Hz重采样后）。
   - 两个并行深度卷积核：k=5（25ms，响应β/γ波段≥13Hz）和k=15（75ms，响应δ/θ/α波段<13Hz）。
   - 公式：`f1 = ReLU(BN(DWConv_{k=5}(x)))`, `f2 = ReLU(BN(DWConv_{k=15}(x)))`
   - `x_CNN = ReLU(BN(PWConv([f1; f2]))) + x` （残差连接）
   - 仅928个可学习参数，每个通道独立滤波，不引入通道间混合。

2. **片段嵌入**：每个patch通过共享线性层从200维投射到d=200的嵌入空间。

3. **GCN空间脑网络建模**：
   - 将16个EEG通道视为图节点，使用**完全可学习邻接矩阵A**（初始化均匀矩阵，通过反向传播优化）。无需电极坐标，适用于双极导联（CHB-MIT）和参考导联（SIENA）。
   - 对称归一化：`A_hat = D^{-1/2} (A+I) D^{-1/2}`
   - 两层图卷积：`H^{(l+1)} = ReLU(A_hat H^{(l)} W^{(l)})`，随后残差连接与层归一化。
   - 确保空间混合后的特征仍保留时序结构供后续Mamba处理。

4. **EEG Mamba编码器**：
   - 将GCN输出重塑为 `B × 160 × 200`（160 = 16通道 × 10片段），送入12个级联双向Mamba块。
   - Mamba块使用内容依赖选择性状态空间模型（SSM），O(L)复杂度，内部含核宽4的深度卷积作为短期平滑组件。双向处理允许每个位置整合上下文。

5. **BiLSTM序列汇总**：
   - 双向LSTM（隐藏层128维），将前后向最终隐藏状态拼接为256维全局向量h。
   - 捕获不对称时间动态，为分类提供全局描述。

6. **分类头**：两层MLP（256→64→1），Dropout p=0.3，Sigmoid输出癫痫概率p∈[0,1]。

7. **事件级假阳性率评估**：
   - 使用1秒步长的滑动窗口，60秒因果移动平均产生风险曲线R(t)。
   - 阈值θ*由验证集Youden指数确定。
   - **持续性滤波器**：R(t)≥θ*持续≥30秒则触发警报，R(t)<θ*持续≥60秒则重置。模拟临床神经刺激器滞后逻辑。
   - 事件级指标：`Se_event = |E_TP|/(|E_TP|+N_missed)`，`FPR_event = |E_FP|/T_inter`（T_inter为纯发作间期时长）。仅当警报事件与pre‑ictal窗口有重叠即计为真阳性（无需最小重叠时长）。
   - 平均前置时间：真阳性警报触发点到癫痫发作起点的时间间隔。

## 3. 实验设计

### 3.1 数据集
- **CHB-MIT**：22名儿科患者（排除chb12），原始采样256Hz，双极导联。统一使用16个共同导联（FP1-F7等）。pre-ictal窗口：发作前30分钟。发作间期窗口：前后4小时无发作。
- **SIENA**：6名成人患者（排除8名因无连续30分钟pre-ictal数据），原始采样512Hz，参考导联。同样匹配16个导联。pre-ictal窗口：30分钟。
- 预处理：带通滤波0.5–40Hz（防止混叠）→陷波滤波（50/60Hz）→重采样至200Hz→振幅伪迹剔除（±500μV）→10秒非重叠窗口→每通道标准化。
- 训练时对发作间期窗口进行随机欠采样以平衡类别（但测试集从不欠采样）。

### 3.2 对比方法
- **Jemal et al. (2024)**：唯一使用严格留一患者方案的可比方法。其无域适应结果：CHB-MIT AUC 0.69，SIENA AUC 0.48；域适应后（CDAN+E）：CHB-MIT 0.75，SIENA 0.61。
- **CLSP-REQA（2026）**：在CHB-MIT上AUC 0.7426±0.0199，SIENA上0.7012±0.0249（实质上是Mamba-BiLSTM基线，见消融实验）。
- 注意：仅对比同样采用**严格患者独立评估**的方法，排除使用随机/患者特定划分的文献。

### 3.3 实验设置
- **评估协议**：留一患者交叉验证（LOPO）× 5个独立随机种子。每个患者依次作为测试集，剩余患者训练。共产生CHB-MIT 110个测试估计（22×5），SIENA 30个（6×5）。
- **超参数**：AdamW优化器，学习率3e-4，权重衰减1e-4，余弦退火50轮，预热5轮，batch size 64，Dropout 0.3，嵌入维度200，Mamba SSM状态大小64，Mamba层12，BiLSTM隐藏层128。所有超参数在两个数据集上固定。
- **主要指标**：AUC-ROC（主指标），窗口级灵敏度/特异性/准确率（Youden阈值），事件级FPR（次/小时）和平均前置时间。

## 8. 不足与局限

1. **回顾性评估**：所有结果基于预先录制的EEG数据离线分析，虽然风险曲线因果计算可实时实现，但统计量不能直接等同于前瞻性临床报警率。需要实时环境验证。
2. **固定pre-ictal horizon**：统一使用30分钟，忽略了患者间和发作类型间的差异，适应能力有限。
3. **仅头皮EEG**：未验证于颅内EEG（如NeuroPace RNS系统数据），临床转化的关键一步缺失。
4. **SIENA数据集样本小**：仅6名患者可用，统计稳定性有限，且GCN在SIENA上未带来明显AUC提升（反而下降），说明空间建模的增益可能依赖数据特性或患者异质性。
5. **超参数未在SIENA上独立调优**：使用与CHB-MIT完全相同的超参数，虽然体现泛化性，但可能非SIENA最优。超参数敏感性分析仅在CHB-MIT上完成。
6. **边缘部署未验证**：模型复杂度（12层Mamba+BiLSTM+MLP）在植入设备上的推理延迟、功耗等未评估，需要模型压缩后才能实用。
7. **缺少多任务或脑电基础模型对比**：未与近期EEG基础模型（如LaBraM, BrainVT等）在跨患者任务上对比。
8. **事件级评估中阈值选取依赖于验证集Youden指数**，在实际临床中标签获取困难，可能需要无监督或自适应阈值。
