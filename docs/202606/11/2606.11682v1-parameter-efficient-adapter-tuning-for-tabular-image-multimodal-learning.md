## 摘要
表格-图像多模态学习旨在通过联合使用结构化表格属性和视觉数据来改进预测建模。尽管预训练编码器提供了强大的模态特定表示，但完全微调可能计算成本高昂，而保持编码器冻结则可能限制任务特定适应性。我们提出了表格-图像适配器（TI-Adapter），一种基于模态特定适配器的微调框架，用于高效的多模态适应。TI-Adapter冻结预训练的表格编码器，并在提取的表格嵌入后学习一个适配器，同时通过嵌入级和瓶颈级适配器来适应图像分支，而不是完全微调。在20个表格-图像数据集上的实验表明，TI-Adapter在显著减少可训练参数的同时，实现了与完全微调相当或更优的预测性能。消融研究进一步证明了适配器放置对于平衡性能和实际效率的重要性。

## Abstract
Tabular-image multimodal learning aims to improve predictive modeling by jointly using structured tabular attributes and visual data. Although pretrained encoders provide strong modality-specific representations, full fine-tuning can be computationally expensive, while keeping encoders frozen may limit task-specific adaptation. We propose the Tabular-Image Adapter (TI-Adapter), a modality-specific adapter-based fine-tuning framework for efficient multimodal adaptation. TI-Adapter freezes the pretrained tabular encoder and learns an adapter after the extracted tabular embedding, while adapting the image branch with embedding-level and bottleneck-level adapters instead of full fine-tuning. Experiments on 20 tabular-image datasets show that TI-Adapter achieves competitive or better predictive performance than full fine-tuning while using substantially fewer trainable parameters. Ablation studies further demonstrate the importance of adapter placement for balancing performance and practical efficiency.

## 2. 论文提出的方法论

### 核心思想
- 冻结两个预训练编码器（TabPFN-v3 + ResNet-50），仅训练少量适配器模块和最终线性预测头。
- 对不同模态设计不同的适配器结构：表格分支使用嵌入级瓶颈适配器；图像分支可选择嵌入级适配器或插入到ResNet瓶颈块中的卷积适配器（ConvAdapter）。

### 关键技术细节
1. **表格适配器**：
   - 输入：表格特征向量 \(X \in \mathbb{R}^d\)，通过冻结的TabPFN提取嵌入 \(E_T \in \mathbb{R}^{d_T}\)。
   - 适配器公式：
     \[
     A_T(E_T) = W_{\text{up}}^T \sigma(W_{\text{down}}^T E_T + b_{\text{down}}^T) + b_{\text{up}}^T
     \]
     其中 \(W_{\text{down}}^T \in \mathbb{R}^{r_T \times d_T}\) 降维，\(W_{\text{up}}^T \in \mathbb{R}^{d_T \times r_T}\) 升维，\(r_T\) 为瓶颈维度（设为16），\(\sigma\) 为非线性激活。
   - 残差连接：\(\tilde{E}_T = E_T + \alpha_T A_T(E_T)\)，\(\alpha_T = 1\)。

2. **图像适配器（两种策略）**：
   - **嵌入级图像适配器（EAdapter）**：在ResNet-50最终嵌入 \(E_I \in \mathbb{R}^{d_I}\) 后添加类似结构，残差连接输出 \(\tilde{E}_I\)。
   - **瓶颈级卷积适配器（BCAdapter）**：在ResNet的瓶颈块后插入ConvAdapter模块：
     \[
     A_C(F_{\ell,j}) = \text{Conv}_{\text{up}}^{1\times1}\left( \sigma\left( \text{Conv}_{\text{down}}^{3\times3}(F_{\ell,j}) \right) \right)
     \]
     其中 \(F_{\ell,j}\) 为特征图，通道先降至 \(r_C\)（16）再升回原通道，残差连接 \(\tilde{F}_{\ell,j} = F_{\ell,j} + \alpha_{\ell,j} A_C(F_{\ell,j})\)。

3. **融合与预测**：将适应后的表格嵌入与图像嵌入拼接，输入线性层做分类或回归：
   \[
   Z = [\tilde{E}_T, \tilde{E}_I] \in \mathbb{R}^{d_T + d_I}, \quad o = W_o Z + b_o
   \]

### 算法流程（文字说明）
- 前向：输入表格和图像 → 冻结编码器提取特征 → 分别通过适配器调整 → 拼接 → 线性预测。
- 训练：仅适配器和线性头参数可更新，编码器参数冻结；使用AdamW优化器、学习率衰减、早停。

## 3. 实验设计

- **Benchmark**：统一数据划分（80%训练、20%测试，训练集中再留20%验证），图像resize至256×256，TabPFN嵌入维度512，ResNet-50嵌入维度2048。

## 6. 论文的主要结论与发现

1. **BCAdapter2（layer3+layer4插入适配器）在所有方法中取得最佳平均性能**，在12分类任务上平均排名2.08（优于全微调的2.25），在6个数据集上最佳；8回归任务平均排名1.63（优于全微调的2.25），在4个数据集上最佳。
2. **适配器微调可显著减少可训练参数**（BCAdapter2仅9.22%），但GPU内存并非等比例下降（BCAdapter2内存约为全微调的38.4%）；插入更多层（BCAdapter4）甚至导致内存超过全微调。
3. **适配器放置位置至关重要**：仅在最终嵌入适配（EAdapter）提升有限；在高分辨率特征图插入适配器（layer3+layer4）效果最好；插入更早层（layer1-2）收益边际且内存代价大。
4. **表格分支冻结+适配器有效**：TabPFN的上下文学习能力无需更新参数，嵌入级适配器即可提供任务适应性。
5. **TI-Adapter可作为全微调的实际替代方案**，尤其适合资源受限场景。
