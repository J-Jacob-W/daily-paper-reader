## 摘要
开放图像到文本生成（OpenITG）的增量学习（IL）使模型能够持续为新图像生成准确且上下文相关的文本，同时保留先前获得的知识。与先前研究不同，本文解决了一个更实际的场景，其中视觉数据的主要类别随环境演变而随时间变化。在此背景下，我们引入了持续对齐的新概念，即逐步调整预训练视觉语言模型（VLM）中的对齐模块，以保持高质量的跨模态表示。基于此思想，我们提出高效持续对齐（ECA），一种新颖的无样本IL方法用于OpenITG。关键挑战是使模型能够获取新的任务特定特征，同时最小化对已建立对齐的干扰，且无需访问先前任务的原始数据。为解决这一问题，ECA采用三种核心机制：混合查询（MoQ）模块，用于适配任务特定查询标记；基于Fisher信息矩阵（FIM）度量的Fisher动态扩展（FeDEx），动态扩展模型结构；以及带有字典回放（DR）的嵌入字典，以保留过往知识。为评估ECA性能，我们构建了四个更贴近真实场景的新IL OpenITG基准测试。实验结果表明，与基线方法相比，ECA显著缓解了灾难性遗忘并提升了IL性能。代码和基准测试见https://github.com/Snowball0823/ECA。

## Abstract
Incremental Learning (IL) for Open-ended Image-to-Text Generation (OpenITG) enables models to continuously generate accurate, contextually relevant text for new images while preserving previously acquired knowledge. Unlike prior studies, this paper addresses a more practical scenario in which the predominant category of visual data shifts over time as environments evolve. In this context, we introduce a new notion of continual alignment, which incrementally adapts the alignment module within pre-trained VLMs to preserve high-quality cross-modal representations. Based on this idea, we propose Efficient Continual Alignment (ECA), a novel exemplar-free IL approach for OpenITG. The key challenge is enabling the model to acquire new, task-specific features while minimizing interference with the established alignment without accessing raw data from previous tasks. To address this, ECA employs three core mechanisms: a Mixture of Query (MoQ) module that adapts task-specific query tokens, a Fisher Dynamic Expansion (FeDEx) that dynamically expands model structure based on a Fisher Information Matrix (FIM)-based metric, and an embedding dictionary with Dictionary Replay (DR) to retain past knowledge. To evaluate ECA's performance, we construct four new IL OpenITG benchmarks that better reflect real-world scenarios. Experimental results demonstrate that ECA significantly mitigates catastrophic forgetting and improves IL performance compared to baseline methods. Code and benchmarks are available at https://github.com/Snowball0823/ECA.

## 1. 论文的核心问题与整体含义（研究动机和背景）

现有开放图像到文本生成（OpenITG）的增量学习（IL）方法大多假设不同任务间的图像类别是**互斥的**（如只保留单一物体类别的图像），但真实场景中视觉内容会随着环境变化而不断漂移——同一图像可能包含多个语义元素，其主导语义（“主要主题”）随时间改变。这带来了三个核心挑战：

- **C1**：不同任务之间语义重叠（overlapping semantics），且没有任务标识符，模型需要组合复用先前习得的线索；
- **C2**：在不保存原始样本（exemplar-free）的情况下维持已建立的跨模态对齐；
- **C3**：语义重叠会导致参数冲突，必须在适应新任务时缓解。

为此，论文首次提出“**持续对齐（continual alignment）**”概念，专注于调整预训练VLM中的**对齐模块**（如BLIP-2的Q-Former），以实现高效、无样本的增量学习。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
ECA是一个**无样本（exemplar-free）框架**，仅更新对齐模块（Q-Former），保持视觉编码器和语言模型冻结。通过三个模块协作：**MoQ（混合查询）**、**FeDEx（Fisher动态扩展）**、**DR（字典回放）**，在不访问旧数据的情况下实现新任务能力获取与旧知识保持。

### 关键技术细节

#### （1）Mixture of Query (MoQ)
- 为每个任务学习一组**任务特定的查询标记（query tokens）** 和一个**任务特定的键（key）**。
- 在推理时，利用注意力机制将当前图像的视觉平均嵌入与所有已学键进行匹配，动态聚合对应的查询标记，并与预训练查询标记相加。
- 通过**正交性损失**和**键对齐损失**优化，防止新任务查询干扰旧任务，并确保键与当前图像嵌入相关。

#### （2）Fisher Dynamic Expansion (FeDEx)
- 在Q-Former的每层自注意力与前馈网络中插入**并行适配器（Parallel Adapter, PA）**。
- 推导了一个基于**Fisher信息矩阵（FIM）** 的指标\( S(\omega_t) \)。当\( S(\omega_t) > 0.5 \)时，说明当前PA更新会严重损害旧任务性能，此时**动态扩展一个新的PA**；否则复用现有PA。
- 扩展后固定旧PA，对各PA输出取均值作为最终输出，既保留旧对齐又分配新容量。

#### （3）Dictionary Replay (DR)
- 通过**稀疏字典学习**（Lasso + FISTA）从视觉嵌入中学习一个过完备字典\( D \)，每个样本可表示为少量原子的稀疏线性组合。
- 在训练新任务时，回放字典重建的嵌入，使用**知识蒸馏损失**保持当前模型输出与旧模型输出一致，无需存储原始图像。

#### 整体训练流程
- 每个任务先根据FeDEx指标决定是否扩展PA；
- 联合优化：交叉熵损失 + MoQ损失（正交+对齐）+ DR损失（平衡系数\(\lambda\)）；
- 任务结束后用稀疏字典学习更新词典。
