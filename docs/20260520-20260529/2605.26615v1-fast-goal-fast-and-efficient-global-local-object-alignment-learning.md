## 摘要
视觉-语言模型如CLIP在图像与文本对齐方面展现出令人印象深刻的能力，但由于在简短文本描述上进行预训练，它们在处理冗长且详细的文本描述时常常遇到困难。我们提出了FAST-GOAL（快速高效的全局-局部对象对齐学习），这是一种高效的微调方法，通过全局-局部语义对齐增强了CLIP处理长文本的能力。我们的方法包含两个关键组件。首先，快速局部图像-句子匹配（FLISM）通过目标检测和空间划分高效提取局部图像区域，然后将其与对应的句子进行匹配。其次，基于标记相似性的学习（TSL）最大化图像中特定区域的块标记与其对应区域嵌入之间的相似性，并对文本应用相同原理，从而增强模型捕捉细节对应关系的能力。此外，我们引入了GLIT100k数据集，该数据集提供了全局图像-长文本描述对以及上下文导出的局部对，其中局部描述从全局描述中提取以保持语义连贯性。通过在长文本数据集（DOCCI、DCI）和短文本数据集（MSCOCO、Flickr30k）上的广泛实验，我们证明了FAST-GOAL在保持计算效率的同时，相比基线方法取得了显著改进，使CLIP能够有效适应详细的文本描述。

## Abstract
Vision-language models such as CLIP have shown impressive capabilities in aligning images and text, but they often struggle with lengthy and detailed text descriptions due to pre-training on short and concise captions. We present FAST-GOAL (Fast and Efficient Global-local Object Alignment Learning), an efficient fine-tuning method that enhances ability of CLIP to handle lengthy text through global-local semantic alignment. Our method consists of two key components. First, Fast Local Image-Sentence Matching (FLISM) efficiently extracts local image regions through object detection and spatial division, then matches them with corresponding sentences. Second, Token Similarity-based Learning (TSL) maximizes the similarity between patch tokens from specific regions in the image and their corresponding region embeddings, applying the same principle to text, which enhances the ability of the model to capture detailed correspondences. Additionally, we introduce GLIT100k, a dataset that provides both global image-lengthy caption pairs and context-derived local pairs, where local descriptions are extracted from global captions to maintain semantic coherence. Through extensive experiments on long caption datasets (DOCCI, DCI) and short caption datasets (MSCOCO, Flickr30k), we demonstrate that FAST-GOAL achieves significant improvements over baselines, enabling effective adaptation of CLIP to detailed textual descriptions while maintaining computational efficiency.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 同时利用全局（整张图像与整段文本）和局部（图像子区域与对应句子）的对齐信号进行微调，使 CLIP 编码器能关注图像和文本中的主导局部元素，从而产生更具代表性的 embedding。
- 两个关键组件：**FLISM**（高效构建局部对）和 **TSL**（利用局部对进行细粒度对齐学习）。

### 关键技术细节

#### （1）Fast Local Image-Sentence Matching (FLISM)
- **输入**：一对全局图像 \(I_g\) 和其长文本描述 \(T_g\)。
- **图像局部提取**：
  - 使用轻量级目标检测模型 YOLOS 检测图像中的物体，得到检测框区域。
  - 补充默认的空间划分：四个象限（quadrants）和一个中心区域。
  - 合并得到局部图像集合 \(\{I_{l,i}\}_{i=1}^N\)。
- **文本局部提取**：将全局描述 \(T_g\) 按句拆分为句子集合 \(\{T_{l,i}\}_{i=1}^M\)。
- **匹配策略**：
  - 使用 CLIP 文本编码器提取每个句子的 CLS 嵌入 \(\{t^{\text{cls}}_{l,i}\}\)。
  - 使用 CLIP 图像编码器提取每个局部图像的 CLS 嵌入 \(\{v^{\text{cls}}_{l,i}\}\)。
  - 计算所有句子与局部图像的余弦相似度，为每个句子选择相似度最高的局部图像作为候选对。
  - 从所有候选对中选出相似度最高的一对，记为 \((I_l, T_l)\)，作为该样本的唯一局部对。

#### （2）Token Similarity-based Learning (TSL)
- 对于全局文本 \(T_g\)，通过文本编码器得到所有序列 token \(S_g \in \mathbb{R}^{M \times d}\)。利用句子在全局文本中的位置索引集合 \(\mathcal{T}\)，平均池化得到该句子的 token 特征 \(S_m\)，再经过投影得到 \(\hat{S}_l = \psi_t(S_m)\)。
- 对于全局图像 \(I_g\)，通过视觉编码器得到所有 patch token \(P_g \in \mathbb{R}^{N \times d}\)。利用局部图像 \(I_l\) 的边界框坐标 \((x_1, y_1, x_2, y_2)\)，筛选落在此框内的 patch token 索引集合 \(\mathcal{B}\)，平均池化得到特征 \(P_m\)，再投影得到 \(\hat{P}_l = \psi_v(P_m)\)。
- 损失函数：最大化投影 token 嵌入与对应局部 CLS 嵌入之间的相似度（即让相似度矩阵对角线元素趋近于 1）。
  \[
  \mathcal{L}_{\text{TSL}} = \text{MSE}\big(\text{sim}(\hat{P}_l, v^{\text{cls}}_l), 1\big) + \text{MSE}\big(\text{sim}(\hat{S}_l, t^{\text{cls}}_l), 1\big)
  \]
- 整体损失：
  \[
  \mathcal{L}_{\text{total}} = \lambda_{\text{global}} \mathcal{L}_{\text{global}} + \lambda_{\text{local}} \mathcal{L}_{\text{local}} + \lambda_{\text{TSL}} \mathcal{L}_{\text{TSL}}
  \]
  - \(\mathcal{L}_{\text{global}}\)：全局图文对的对比学习损失。
  - \(\mathcal{L}_{\text{local}}\)：局部图文对的对比学习损失。
  - 超参数 \(\lambda_{\text{global}} = 1, \lambda_{\text{TSL}} = 1, \lambda_{\text{local}} = 0.5\)。

## 7. 优点

- **高效性**：FLISM 使用轻量级检测器代替 SAM，大幅降低预处理时间；仅需 100k 数据微调，总参数减少 2.2 倍，训练耗时 1-2 小时，可扩展性强。
- **通用性**：在长、短文本场景均保持优秀性能，无过拟合风险。
- **创新性**：TSL 通过 token 级相似性学习实现了局部区域与其在全局图像/文本中对应位置的特征对齐，是细粒度对齐的有效手段。
- **数据集设计**：GLIT100k 的上下文导出局部对保持了全局-局部语义一致性，避免了独立生成导致的语义断层。

- **鲁棒性验证**：注入错误描述的实验表明 FAST-GOAL 对部分错误具有鲁棒性（性能下降最小）。

## 8. 不足与局限

- **依赖 MLLM 生成文本**：GLIT100k 使用 LLaVA-Next 生成长文本，虽然质量接近人工标注，但生成过程中仍可能引入幻觉或偏见；未使用人工标注的长文本数据进行训练。
- **视觉 backbone 仅限 ViT**：所有实验基于 ViT-B/16 和 ViT-L/14，未探索其他架构（如 ConvNeXt 等）。
- **仅处理英文文本**：数据集和模型均针对英文，多语言场景未验证。
- **局部对数量限制**：FLISM 仅选择最高相似度的一个局部对用于训练，可能丢失其他潜在有效对应关系。虽然实验显示单对优于 Top-3，但更复杂的动态选择策略可能进一步提升上限。
- **硬负样本挖掘未成功**：尝试使用同图像内其他局部对作为硬负样本会导致性能下降，论文未给出更优的硬负样本策略。
- **未见在其他视觉-语言任务上的验证**：如视觉问答（VQA）、图像描述生成等任务未涉及，应用范围有限。
- **训练数据规模较小**：GLIT100k 仅 10 万对，虽然实验表现良好，但更大规模的数据是否会带来进一步收益未探索。
