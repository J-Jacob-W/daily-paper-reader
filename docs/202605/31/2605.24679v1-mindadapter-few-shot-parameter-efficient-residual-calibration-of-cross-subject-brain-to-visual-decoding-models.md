## 摘要
跨被试脑-视觉解码由于严重的个体间差异导致系统性的被试特定功能错位，这仍然是脑机接口领域的核心挑战。为解决此问题，我们提出MindAdapter，一种面向预训练脑-视觉解码模型的参数高效少样本校准框架。MindAdapter采用解耦的线性-残差级联对齐范式，冻结预训练的显式脑功能对齐骨干网络（粗粒度），并引入轻量级非线性残差适配器（细粒度），从而将全局跨被试对应关系与被试特定残差校正解耦，实现细粒度的空间与语义校准。为保持全局表征稳定性，我们设计了一种拓扑锚定的双流流形约束：少量共享刺激作为拓扑锚点，提供体素级配对监督；同时，语义流通过冻结的视觉-语言解码器在未配对脑数据上施加一致性约束。综上，MindAdapter高效注入被试特定校正，同时保持预训练期间学习的全局表征几何结构。在自然场景数据集（NSD）上的实验表明，MindAdapter仅使用少量共享刺激即可显著提升跨被试视觉重建与检索精度，为个性化脑-视觉解码提供了实用且数据高效的解决方案。

## Abstract
Cross-subject brain-to-visual decoding remains a core challenge in brain-computer interfaces due to severe inter-individual variability that induces systematic subject-specific functional misalignment. To address this issue, we propose MindAdapter, a parameter-efficient few-shot calibration framework for pretrained brain-to-visual decoding models. MindAdapter adopts a decoupled linear-residual cascade alignment paradigm by freezing a pretrained explicit brain functional alignment backbone (coarse) and introducing a lightweight nonlinear residual adapter (fine), thereby disentangling global cross-subject correspondence from subject-specific residual corrections for fine-grained spatial and semantic calibration. To further preserve global representational stability, we design a topology-anchored dual-stream manifold constraint, where a small set of shared stimuli serves as topological pins with voxel-level paired supervision, while a semantic stream enforces consistency through a frozen vision-language decoder on unpaired brain data. Together, MindAdapter efficiently injects subject-specific corrections while maintaining the global representational geometry learned during pretraining. Experiments on the Natural Scenes Dataset (NSD) demonstrate that MindAdapter substantially improves cross-subject visual reconstruction and retrieval accuracy using only a few shared stimuli, offering a practical and data-efficient solution for personalized brain-to-visual decoding.

- **核心问题**：跨被试脑-视觉解码中，不同个体的脑活动存在系统性差异（如皮层组织、神经调谐、体素布局不同），导致基于一个被试训练的模型难以泛化到新被试。现有方法（如 MindAligner）通过线性脑转移矩阵（BTM）进行全局对齐，但无法捕捉细粒度的被试特定残差错位，因此解码精度受限。
- **整体含义**：为了解决这一问题，论文提出一种**少样本、参数高效的残差校准框架** MindAdapter，仅需少量共享刺激即可校正跨被试错位，实现个性化脑解码，提升视觉重建和检索的保真度。

### 方法论

- **核心思想**：采用**解耦的线性–残差级联对齐**范式，将全局跨被试对应关系与被试特定残差校正分离。具体地：
  1. **粗对齐**：冻结预训练的线性 BTM 网络 \(F_0\)，它学习从源被试体素空间到目标被试体素空间的粗略映射。
  2. **细校准**：在 \(F_0\) 后添加一个轻量级**非线性残差适配器** \(A_\theta\)，学习残差 \(\mathbf{r}(\mathbf{x}_s)\)，使得校准后的映射 \(F_\theta(\mathbf{x}_s) = F_0(\mathbf{x}_s) + A_\theta(F_0(\mathbf{x}_s))\) 逼近真实映射 \(F^*(\mathbf{x}_s)\)。
- **关键技术细节**：
  - **残差适配器结构**：三层 MLP，隐藏维度 4096，激活函数 GELU。仅 88M 可训练参数，其余部分冻结。
  - **拓扑锚定双流流形约束（损失函数）**：

- **算法流程**（文字说明）：

  - 初始化残差适配器 \(A_\theta\)，冻结 \(F_0\) 和 \(G\)。

- **对比方法**：

  - **MindEye2**：通过岭回归将多被试信号对齐到共享空间，然后解码。

### 资源与算力

- **GPU**：单个 NVIDIA H100 GPU。

- **训练时间**：MindAdapter 的少样本校准可在数分钟内收敛；MindAligner 需要数小时，MindEye2 超过一天。论文明确提到：“training typically converges within several minutes on a single H100 GPU”。

### 主要结论与发现

- MindAdapter 在极少量共享刺激（32~64 shot）下，显著提升跨被试视觉重建的图像质量和语义一致性，优于 MindAligner 和 MindEye2。
- 解耦的粗–细校准设计有效分离了全局对齐与个体残差，避免了重训练大模型。
- 拓扑锚定双流损失在少样本下稳定优化，防止语义漂移。
- 参数效率高（88M 可训参数），训练快（几分钟），适合实际部署。

### 优点

1. **数据高效**：仅需 32~64 个共享刺激即可带来显著提升，减少 fMRI 数据采集成本。
2. **参数高效**：仅需引入一个轻量适配器，无需重新训练主干网络，计算开销极小。
3. **粗到细的渐进校准**：保留预训练的全局结构，同时注入个体特定残差，避免灾难性遗忘。
4. **双流损失设计**：锚定流提供强几何约束，语义流保持全局语义，两者互补，实现稳定优化。
5. **广泛的实验验证**：在多被试、多方向、多指标上均表现一致，消融实验充分证明各组件必要性。

### 不足与局限

1. **复杂场景精细性不足**：虽然保留粗语义，但在处理复杂空间布局、多目标组成场景时仍可能产生结构失真或细节错误（图 9）。
2. **低 shot 限制**：要求至少 16 个共享刺激才能稳定（论文提到 16 shot 是达到稳定性能的近似下限），在实际中若共享刺激极低（<16）可能效果不佳。
3. **单一数据集**：仅使用 NSD（自然图像），未在其它模态（如视频、语言刺激）或更广范的数据集上验证，泛化性待考。
4. **仅针对 fMRI 解码**：未考虑其他脑信号（如 MEG/EEG）或跨模态场景。
5. **未深入分析残差适配器的非线性行为**：论文给出了一阶近似，但对更高阶项的影响缺乏讨论。

### 总结与展望

- **总体评价**：MindAdapter 提出了一种解耦的粗‑细对齐范式，仅需极少量（32～64 shot）共享刺激即可高效校准跨被试 fMRI 映射。该方法保留了预训练全局对齐的拓扑结构，同时通过轻量残差适配器弥补个体特异性的细粒度错位，在视觉重建和检索任务上显著优于现有方法（MindAligner、MindEye2）。其参数高效（88M 可训参数）和训练快速（数分钟）的特点使其具备实际部署价值。
- **对领域的贡献**：该工作首次将“残差适配器”思想引入脑信号跨被试对齐场景，打破了以往需要大量配对数据或重新训练大模型的做法。其双流损失（锚定流+语义流）为少样本下的多模态对齐提供了一个稳定的优化策略，有望推广至其他跨被试/跨模态脑解码任务（如语言、运动、EEG/MEG）。
- **未来工作建议**：
  1. **更极端的少样本场景**：探索能否在 8～16 shot 下通过数据增强、元学习或自监督预训练进一步降低共享刺激需求。
  2. **更复杂的脑网络建模**：当前仅考虑体素级对齐，未来可结合功能连接图或图神经网络捕捉区域间拓扑差异。
  3. **多模态/多数据集泛化**：在视频刺激、听觉刺激或跨数据集（如 BOLD5000、HCP）上验证方法的通用性。
  4. **可解释性与生物学意义**：分析残差适配器学到的个体特异性映射反映了哪些神经生理差异（如皮层折叠、感受野偏侧），为脑机制研究提供线索。
